## PDF 해석 보정

[문서 가이드](https://app.notion.com/p/032efe226cee83088c44814bc72e455a)의 PMM PDF는 ISO 표준 문서를 제안·계획·개발·발간하는 과정과 사례를 다룬다. 8쪽에는 표준 개발 일정 예시가 있고, 두 번째 PDF는 그 과정의 역할·역량을 다룬다. 일반 SI 프로젝트의 모든 개발 산출물을 의무화하는 양식집으로 해석하지 않는다. 본 앱에는 범위·계획·진척·리스크라는 일반 개념만 참고한다.

## 작성 방식에 반영할 점

- 구조화된 요구·기능·WBS·화면 목록·테스트는 같은 ID와 관계를 보존하고 문서 보기로 표현한다.
- 각 문서는 적용 스킬·스킬 revision, 양식 출처·버전, 실제 예시 출처·확인 상태, 입력 자료를 따로 가진다.
- 참조 없음·404·빈 페이지·파일 추출 실패·시각 미검토는 다른 상태다. 실패 항목에 공개 양식을 제안해도 원본 확인 상태를 바꾸지 않는다.
- 원본 업무 내용은 해당 프로젝트 입력으로만 사용한다. 공개 registry와 샘플에는 일반 필드만 남긴다.
- 실제 작성 규칙은 [스킬 실행 설계](08-skill-runtime-and-portability.md)를 따른다. 이번 조사는 작성용 스킬 자체를 수정하거나 Hub에 배포한 작업이 아니다.
