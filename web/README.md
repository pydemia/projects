# Projects 웹 클라이언트

React 19.3.1 · TypeScript 7.0.2 · Vite 8.3.4 · Node.js 24.
의존성 버전은 `package.json`과 `package-lock.json`에 고정합니다.

```powershell
npm ci
npm run dev
```

앱은 <http://127.0.0.1:5173>에서 열립니다. `/api`와 `/health`는
기본 <http://127.0.0.1:18731>로 전달합니다. API 주소가 다르면 실행 전에
설정합니다.

```powershell
$env:PROJECTS_API_URL = "http://127.0.0.1:18731"
npm run dev
```

개발 프록시는 원래 Host·Origin을 보존합니다. 배포할 때에도 웹 앱과
API를 같은 출처로 제공해야 세션 cookie와 CSRF 검사가 동작합니다.
브라우저에 API 키나 Codex 인증 원문을 저장하지 않습니다. 실행 공급자는
서버의 `projects.local.yaml`에서 설정합니다.

```powershell
npm run check
npm run build
```

`check`는 타입 검사와 Vitest 회귀 검사를 실행합니다. 검사에서는 잘못된
API 성공 응답, CSRF 전달, 409 구분, 초안 보존·병합, HTML 비실행,
공급자 미설정과 후보 선택 적용을 확인합니다. 테스트용 mock 응답은
`*.test.ts(x)`와 `fixtures.test-data.ts`에만 있으며 제품에 예시 결과를
표시하는 경로는 없습니다.

로그인 후 프로젝트를 만들고 기획·작업·테스트·관계·영향 검토·기준선을
관리합니다. 스킬 작업의 대기·실행·실패·취소·검토·적용 상태는 실제 API
응답으로 표시합니다. 실행 결과는 사용자가 선택하기 전 본문을 바꾸지
않습니다. 실행 상태는 활성 화면에서 최대 5분 자동 확인하며, 이후에는
수동으로 최신 상태를 불러올 수 있습니다.

문서는 **임시 Markdown 저장소**입니다. 제목·본문·종류·참조 선택,
스킬 작성·수정·검수, Markdown·실행 묶음 반출을 제공합니다. 문서 관리는
Note 연계 예정이며 Office 편집·문서 확정·버전 탐색·외부 문서 재연결 UI는
현재 범위에 포함하지 않습니다. revision 숫자는 저장 충돌 검사에
사용합니다. 다른 업무 객체의 이력과 복원 기능은 유지합니다.

편집 초안은 사용자·프로젝트·객체별로 이 브라우저에 임시 보관합니다.
브라우저 저장소가 불가능하면 화면에 알리며, 서버 응답 전에는 저장
완료로 표시하지 않습니다. Markdown은 HTML을 허용하지 않고 외부 이미지는
자동 요청하지 않는 링크로 표시합니다. Mermaid 코드 블록은 원문으로
읽고 편집할 수 있으며 도식 렌더링은 현재 제공하지 않습니다.
